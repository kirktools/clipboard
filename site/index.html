核心功能

最近历史与即时搜索

默认保留最近 50 条（可调 10–500 条），支持纯文本、链接及多格式图片（含截图、浏览器复制与访达图片文件）。重复复制自动去重并更新最近时间。

独立长期收藏

一键收藏常用命令、提示词、链接或图片，支持自定义名称与搜索。收藏独立存储，不占历史上限，清空最近历史或重启后仍完整保留。

键盘优先与可钉住面板

支持自由拖动、调整大小与钉住窗口（⌘P）。钉住后切到其他应用不自动收起，适合连续多条复制粘贴；配合 Hotkey 可用全局快捷键一键呼出。

可控记录与应用内更新

菜单栏与面板随时暂停/恢复记录；正式版支持在菜单栏手动「检查更新…」，经校验和、架构与发布者证书核验后由用户确认安装。

隐私行为与边界

  • 仅存本机：历史、收藏与图片缓存保存在本机 ~/Library/Application Support/Clipboard/，不上传云端，不接入任何分析统计。
  • 敏感标记过滤与边界：自动跳过明确带有敏感、临时或自动生成标记的剪贴板内容（如 ConcealedType、TransientType、AutoGeneratedType）。但并非所有密码管理器都会写入此类标记，未标记的敏感剪贴板内容仍可能被记录，敏感操作前可使用「暂停记录」。
  • 联网时机：应用日常运行不联网；仅在用户主动点击菜单栏「检查更新…」时连接 GitHub 官方发布接口查询与下载更新包。
  • 诊断日志脱敏：正式版默认关闭本机诊断日志文件（开发版默认开启）；系统统一日志（OSLog）仅记录少量脱敏状态事件，均不包含剪贴板正文、链接、图片、收藏标题、内容哈希、凭据或个人路径。

安装与更新说明

首次安装（DMG）

  1. 下载上方 Clipboard-macos-arm64.dmg 并打开，将 Clipboard.app 拖入「应用程序」文件夹。
  2. 本项目采用免费开源分发，使用项目固定自签名证书签名，未购买 Apple Developer ID 证书，也未做 Apple 公证。
  3. 首次打开若遇到 macOS 安全提示，请在「系统设置 → 隐私与安全性」中点击「仍要打开」（或在访达按住 Control 点击应用选择「打开」）。

后续更新（ZIP）

  1. 将正式版安装在可写的「应用程序」目录后，点击菜单栏图标 →「检查更新…」。
  2. 确认新版本后，应用会自动下载对应架构的 ZIP、校验 SHA256SUMS、Bundle ID、架构与同证书发布者身份，备份旧版后完成替换。
  3. 若当前为 ad-hoc 本地构建或安装目录不可写，应用内替换会自动停用，并引导打开 GitHub Releases 手动更新。
