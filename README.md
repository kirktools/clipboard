# Clipboard

原生 macOS 菜单栏剪贴板历史与长期收藏工具，基于 Swift、SwiftUI 与 AppKit 实现，无第三方依赖。

## 功能概览

- **最近历史**
  - 常驻菜单栏，自动记录纯文本、网页链接（`http`/`https`）和图片，重启后保留。
  - 默认保留最近 50 条（可在设置中调整为 10–500 条）；重复复制同一内容时更新最近时间并置顶，不产生重复记录。
  - 面板支持按文本、链接与条目名称实时搜索，图片显示缩略图与尺寸信息。
  - 键盘优先操作：`↑`/`↓` 选择，`↩` 复制回系统剪贴板并关闭面板，`⌘1`/`⌘2` 切换「最近 / 收藏」，`⌘D` 收藏或取消收藏，`⌘⌫` 删除，`Esc` 关闭。
- **长期收藏**
  - 最近记录可一键收藏；「收藏」有独立入口，支持改名、搜索、取消收藏和再次复制。
  - 收藏跨重启保留，不占最近历史条数；即使历史因上限被淘汰或用户清空最近，收藏条目及图片依然完整保留。
- **本地存储与隐私控制**
  - 所有数据仅保存在本机 `~/Library/Application Support/Clipboard/`（开发版为 `Clipboard-dev/`），不联网、不上报。
  - 提供「暂停记录」入口，暂停期间不写入新历史。
  - 自动跳过明确标记为敏感、临时或自动生成的剪贴板内容（如 `org.nspasteboard.ConcealedType`、`TransientType`、`AutoGeneratedType` 等）；不会将剪贴板原文、图片或凭据写入诊断日志。
  - 兼容 macOS 15.4+ 剪贴板访问行为（`NSPasteboard.accessBehavior`），在设置中展示当前授权状态。

## 构建与运行

需要 macOS 14+ 与 Swift 6 / Xcode Command Line Tools。

```bash
# 运行测试
make test

# 构建并启动开发版（dist/dev/Clipboard Dev.app）
make dev

# 仅构建发布版（dist/release/Clipboard.app）
make build CONFIG=release
```

静默常驻启动（仅驻留菜单栏，不弹出面板）：

```bash
open "dist/dev/Clipboard Dev.app" --args --background
```

## 与 Hotkey 配合

Clipboard 是独立应用，从菜单栏即可完整使用。如需全局快捷键呼出面板：

1. 在 Hotkey 的「应用快捷切换」中添加 `Clipboard.app`（或开发版 `Clipboard Dev.app`）并绑定快捷键。
2. 三种状态行为：
   - **尚未运行**：按下快捷键拉起 Clipboard 并自动打开历史面板。
   - **已常驻但面板关闭**：按下快捷键激活 Clipboard 并打开历史面板。
   - **面板正在显示**：再次按下快捷键隐藏并收起面板，焦点回到原应用。
3. **划词翻译兼容**：内置 120ms 剪贴板稳定防抖窗口，当 Hotkey 划词翻译临时复制选中文字并迅速恢复原剪贴板时，瞬态内容不会混入历史记录。
